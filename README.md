# Task 1 - Student Grade Management System

## Task Description

This task involves creating a Java program that takes the names and grades of students as input and calculates their average, highest grade, and lowest grade.
The program also displays a summary report containing each student's name and grade.

## Objectives
* Practice Java programming fundamentals.
* Use arrays to store student names and grades.
* Calculate average, highest, and lowest grades.
* Generate a student summary report.

## Technologies Used
* Java
* Scanner
* Arrays

## Features
* Takes the number of students as input.
* Stores student names and grades.
* Calculates average, highest, and lowest grades.
* Displays a summary report of all students.

## How to Run
1. Open `StudentGrade.java` in any Java IDE.
2. Compile and run the program.
3. Enter the number of students, names, and grades when prompted.
4. View the calculated results and summary report.
